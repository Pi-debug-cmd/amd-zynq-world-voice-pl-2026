# 参赛提交要求核对清单

依据：*2026 FPGA 创新设计竞赛题目指南（AMD 赛道）*第 3.3 节，重点核对 3.3.2 至 3.3.5。本仓库不再分发官方指南文件。

| 要求 | 项目包中的证据 | 状态 |
| --- | --- | --- |
| AMD 赛道允许的 FPGA 和申报器件 | README 和硬件说明中记录 Wildfire Zynq-7020、`xc7z020clg400-2` | 已具备 |
| 符合要求的完整 FPGA 工作，允许 PS/HLS 组合 | HLS 最小相位核、PS 运行时/后端、Linux 驱动 | 已具备 |
| 板端运行和测量输出 | Round23 有效实时语音、时序/运行时遥测、无 xrun/回退；Round30 重启后 PL 调用活动 | 用户依据已有 Round23/30 板端证据确认通过；Round24 没有有效语音，不纳入判定 |
| 可复现的源码、构建和仿真材料 | 精简和完整 Vivado 源码包、Tcl、PowerShell、Shell、确定性测试平台；两个干净解压目录均可在 Vivado 2026.1 打开并通过 BD 验证 | 源码已提供；尚未重新完成整机布线，PetaLinux 镜像/工程待补齐 |
| 综合/实现报告与资源数据 | Round17 OOC 报告和 Round18 整机布线报告 | 已提供；外部音频 I/O 延迟约束不完整 |
| PS/PL 协作 | ARM PS 流处理/音频运行时、HLS 最小相位 IP、缓存一致 DMA 驱动、板端调用和回退计数 | 已在 Zynq-7020 上实现并运行 |
| 系统/语音应用目标 | Round9 冻结新会话离线五项门槛报告：身份 0.5200、P10 0.4719、源泄漏 0.0591、UTMOS 3.0789、CER 0.1020；原始 Round10 听感 | 用户确认基本客观通过及主观音色通过 |
| 稳定性和延迟验收 | Round23：20 秒有效语音、分析最大耗时 34.605 ms、无 xrun/ALSA 错误/回退；Round30：重启后候选版本 PL 调用从 2,278 增至 13,751 | 用户依据已有板端证据确认通过；Round24 没有有效语音，不纳入判定 |
| 英文 ASCII 路径和文件名 | 项目包路径均使用英文 ASCII 名称 | 已具备 |
| 范围和限制明确的可复用 Skill | `skill/`，含 PS/PL 提示词流程 | 已提供；提示词流程尚未由其他团队独立试用 |
| AI 协作提示词、回答和修正记录 | `report/AI_COLLABORATION.md` | 部分具备；这是面向本任务的记录，不是全部历史对话的完整导出 |
| 开源许可证 | 项目自编内容使用根目录 MIT 许可证；保留上游 WORLD 许可证 | 已具备；请查看许可证适用范围 |
| 最终交付物（`.bit` / `.xsa` / `.hwh`） | Round30 Release 提供 `.bit`、`.bin.gz`、`.hwh`、`.xsa`、源码包和带 SHA-256 清单的布线报告 | 已提供；PetaLinux 镜像仍待补齐 |
| PYNQ 框架 | 未使用；采用 Linux/PetaLinux C++ PS 运行时 | 自主命题赛道不要求；初学组建议使用 PYNQ |
| 决赛材料 | 官方指南要求决赛队伍准备一页英文海报 | 当前不适用；团队尚未进入决赛 |

本清单描述的是工程提交快照。两个 Vivado 源码包均可重新打开并通过 Block Design 验证；完整源码包不含综合/实现运行输出，项目包也不含 PetaLinux 镜像/工程。用户确认 Round9 五项客观门槛、原始 Round10 听感通过，并依据已有 Round23/Round30 证据接受稳定性和延迟结果。项目技术贡献是实时 WORLD 流程中的 PS/PL 协作，不宣称端到端加速收益。
