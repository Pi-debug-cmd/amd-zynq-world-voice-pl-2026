# Vivado MCP 与 Git 协作技能

本技能帮助贡献者使用项目的 Vivado MCP 流程，并在不干扰并行工作的前提下，发布一轮可追踪的任务成果。

## 文件说明

- `SKILL.md`：任务分流说明和证据边界。
- `references/vivado_mcp.md`：已核对的 MCP 调用、会话管理和常见 Vivado 故障。
- `references/git_github.md`：项目任务认领、分支、提交、推送和 PR 流程。
- `references/round_lessons.md`：近期 PS/PL 轮次中可复用的经验。

## 使用方法

在本仓库执行 Vivado MCP 或 GitHub 工作时，先阅读 `SKILL.md`，再按需查看对应参考文档。命令和路径取自 Windows 项目主机；运行前应在当前机器上确认工具位置和工作目录。
